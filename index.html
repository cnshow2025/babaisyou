遊戲規則說明

場上的文字方塊可以被推動。當它們由左到右或由上到下排成 名詞 是 屬性 的句子時，規則就會立刻生效；把句子拆開，規則就會消失。

讓「你」的物體碰到「贏」的物體就能過關。

屬性效果
你由你操控
贏「你」碰到就過關
停無法穿過
推可以被推動（文字方塊一定可以推）
拉會被拉著跟在後面
擊敗摧毀碰到它的「你」
沉和碰到它的東西一起消失
燙 / 融化「燙」會熔化「融化」的物體
開 / 關兩者相遇時一起消失
移動每回合自己往前走，撞到就回頭
漂浮漂浮，只會碰到同樣漂浮的東西
弱碰到任何東西就壞掉
傳送把站上來的東西傳送到另一個同類物體
輸送像輸送帶一樣移動上面的東西

進階語法：

  • 石頭 是 旗子：把所有石頭變成旗子（巴巴 是 巴巴 可防止被變形）。
  • 巴巴 和 可可 是 你、旗子 是 贏 和 推：用「和」連接。
  • 牆 是 非 停、非 巴巴 是 ...：「非」會否定，並推翻相反的規則。
  • 石頭 有 鑰匙：石頭被摧毀時會留下鑰匙。
  • 石頭 站在 草、石頭 靠近 骷髏、巴巴 面向 旗子：條件式規則。

操作：方向鍵或 WASD 移動、空白鍵等待、Z 復原、R 重來、Esc 回選單。
